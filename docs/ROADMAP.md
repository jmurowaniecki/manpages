# Roadmap

Horizon: approximately the next 12 months from 2026-08.

## Intend to do

- Keep syntax highlighting accurate for common man/roff constructs used when
  authoring pages in VS Code.
- Grow and maintain the `test/syntax/` suite as macros and edge cases are fixed.
- Reach and maintain the OpenSSF Best Practices **Passing** badge; pursue Silver
  criteria that do not require a larger team.
- Keep dependencies and GitHub Actions updated via Dependabot.
- Improve contributor onboarding (labels for small tasks, clearer docs).
- Recruit at least one additional Maintainer to raise the bus factor above 1.

## Do not intend to do

- Become a full man-page renderer, previewer, or `groff`/`mandoc` replacement.
- Add network features, telemetry, or remote fetching of manuals.
- Support every historical roff dialect or vendor macro set.
- Provide a separate GUI outside VS Code / compatible editors that use TextMate
  grammars.

## Near-term milestones

1. Complete Passing-level badge evidence (docs, releases, form answers).
2. Publish Silver governance artifacts already in-tree (CoC, DCO, assurance case).
3. Enable private vulnerability reporting and 2FA requirements on GitHub.
4. Onboard a second Maintainer when a sustained contributor is available.
