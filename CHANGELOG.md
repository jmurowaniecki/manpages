# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Static analysis script and CI steps (`npm run analyze`, `npm run audit`).
- External interface documentation in `docs/INTERFACE.md`.
- Dependabot for npm and GitHub Actions.
- CONTRIBUTING, SECURITY, and CHANGELOG for Best Practices readiness.

### Changed

- Relicensed the project from CC-BY-NC-SA-4.0 to MIT.
- Expanded README (install, secure use, contribution and security links).

## [0.1.3] - 2026-05-27

### Changed

- CI and publish workflow adjustments (Node 25, VSCE publishing).
- README updates for Marketplace install and test command.

## [0.1.1] - 2026-05-27

### Fixed

- Broader parameter coverage in syntax tests ([#4](https://github.com/jmurowaniecki/manpages/issues/4)).

## [0.0.6] - 2026-05-27

### Added

- Additional syntax test scenarios and updated documentation/screenshot.

### Fixed

- Quote matching rules ([#1](https://github.com/jmurowaniecki/manpages/issues/1), [#2](https://github.com/jmurowaniecki/manpages/issues/2)).

## [0.0.4] - 2026-05-27

### Changed

- Documentation and contribution cloning notes.

## [0.0.2] - 2022-03-08

### Changed

- Early packaging and CI updates.

## [0.0.1] - 2021-09-02

### Added

- Initial manpage syntax highlighting extension.
